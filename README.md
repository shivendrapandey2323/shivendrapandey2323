## About Me

I'm **Shivendra Pandey**, a developer in the making with a strong interest in **frontend development**, **UI/UX** and **modern web technologies**. I enjoy turning ideas into responsive, polished interfaces that feel good to use on any screen.

- I focus on writing clean, readable code and building layouts that are accessible and responsive.
- I'm steadily expanding my skills towards **full-stack development**, learning how the frontend, backend and database fit together.
- I learn by building: every project is a chance to improve, solve real problems and understand the "why" behind the code.
- I enjoy collaborating with other developers and exploring new tools and technologies.

> **Currently:** strengthening my frontend fundamentals and learning backend development with Node.js and Express.js.
